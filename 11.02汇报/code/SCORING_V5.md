# MapGPT v5 实验口径

本实验是 2D 文本网格上的原理验证，不是 MapGPT 官方 Matterport3D/Habitat
复现，因此结果只与同一代码库、同一模型、同一 8 张固定地图上的条件比较。

## 固定条件

- 模型：`qwen-plus`，`temperature=0.0`
- 地图：`benchmark_maps_v5.json` 的前 8 张固定 21x21 地图
- 局部观测：5x5
- 最大步数：80
- 每张地图的起点、终点、障碍和语言目标在所有条件中完全一致
- 所有条件均由同一个中转服务调用模型，不在 VM 中保存模型密钥

地图包含办公室隔断、瓶颈通道、回环、迷宫、诱饵支路和死胡同。地图在实验前
生成并冻结，条件运行时不会重新采样。清单中的其余 4 张是未参与本次对照的
预留地图。

## 导航指标

- `SR`：成功到达终点并停止的比例。
- `SPL`：标准定义，失败 episode 记 0：
  `1/N * sum(S_i * l_i / max(p_i, l_i))`。
- `SPL_succ_only`：只对成功 episode 求 SPL，便于和旧版口径核对。
- `OSR`：轨迹中曾经出现终点的比例。
- `NE`：最终位置到终点的 BFS/曼哈顿距离，失败时仍计入。
- `COV`：已观测可走格 / 地图中全部可走格。

## 两种 AP

`AP_FUSED` 是 v5 的主 AP。它衡量结构化地图输出能否重建当前已观测的占用矩阵
和骨架拓扑；缺失的已观测格按错误计，不允许用少量容易格获得虚高分数。

```
cell_accuracy = 正确已观测格 / 全部已观测格
edge_f1 = 预测连通边与真实已观测边的 Jaccard
AP_FUSED = 0.70 * cell_accuracy + 0.30 * edge_f1
```

`AP_LLM_LEGACY` 仍直接调用原 `mapgpt_vm_demo_v4.compute_ap_step()`，用于和旧实验
核对。报告会同时展示两种口径，不能只挑有利数字。

## 公平性说明

- `mapgpt` 条件直接使用原 MapGPT 风格 prompt，LLM 每一步选择一个原始动作。
- `fused_step` 在每步加入同步占用矩阵和拓扑，但仍是逐步动作控制。
- `topo_waypoint` 和 `matrix_waypoint` 分别去掉矩阵或拓扑，作为表征消融。
- `fused_waypoint` 使用 LLM 选择前沿/终点候选，确定性 A* 执行短动作块。
- `risk_waypoint` 在候选选择后增加执行代价、信息增益、死胡同/瓶颈风险检查和
  失败路线暂时否决。它是最终组合方法，不是单独换模型。

所有条件使用相同的地图清单和最大步数。不同条件的 LLM 调用次数也会报告，
以显示分层规划带来的推理成本变化。
