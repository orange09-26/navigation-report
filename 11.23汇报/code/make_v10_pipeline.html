MapGPT v10 完整运行流程图

局部观测 → 矩阵/拓扑/历史 → 地图预测 → 宏观分支 → 打分 → A* → 执行 → 重新判断

① 接任务机器人只知道当前位姿、终点坐标、地图尺寸和局部观测，不知道完整墙体、最短路径或终点所在分叉。
② 决定观测窗口21×21 默认 5×5；大图默认 7×7。若当前格是已知岔路口或局部开阔通道，则下一帧改用 9×9。
③ 有遮挡的局部观测在窗口内从机器人位置做 BFS；看到自由格和相邻墙，墙后区域仍不可见。窗口不是完整真值。
稠密占用矩阵已见自由/墙写入矩阵；未见格子保留“未知”，随后由预测器给出墙概率。
稀疏拓扑每个可见自由格对应 Place ID；相邻自由格连接为边，用来找 frontier 和运行 A*。
轨迹与分支记忆访问轨迹、边访问次数、目标进展；每个分支记录尝试、失败、信息收益和暂时禁用时间。
④ 地图预测
多分辨率 logistic 预测器为每个未知格输出墙概率 p。训练地图与测试地图分离。
⑤ 预测距离
Dijkstra软距离，每个格子代价 = 1 + 7p。预测只是启发式，不作为可直接行走的真实道路。
⑥ Frontier
“已知可走格且旁边有未知格”的位置就是 frontier，表示从已知区域走向未知区域的入口。
⑦ 宏观分支
先找到路径上的首个决策路口，再按“路口 + 出口方向”把附近 frontier 合并成候选分支。
⑧ NMS=4
候选按分数排序；若入口与已保留入口曼哈顿距离＜4，则删除。每个分支最多2个入口，全局最多6个候选。
⑨ 具体航点
候选不是虚的方位，而是具体入口坐标。机器人最终要到达这个格子，再由它进入更深的未知区域。
⑩ 候选打分（分数越低越优先）
score = 1.20×A*去程长度 + 0.80×预计到终点距离 + 2.60×风险 − 0.30×log(1+信息增益) − 0.20×log(1+附近未知量) + 0.60×不确定性 + 历史惩罚 − 历史收益奖励
大图使用预测软距离；小图使用已观察图上的乐观A*距离。历史惩罚来自失败次数和后悔值；历史奖励来自过去信息收益与目标进展。
路径短更接近目标少走窄道能看新区域避免重复失败
⑪ 终点是否已经进入已知拓扑？是：GOAL候选优先。否：选择当前最高分宏观分支入口。
⑫ A*规划实际路线A*只在已确认自由格上搜索，输出“当前位置 → 具体航点入口”的多格路线；同时提供用于打分的真实已知图长度。
⑬ 执行一个低层动作若朝向不对先转向；否则前进一格。转向不改变位置，通常不触发新规划。
⑭ env.step() 更新世界记忆仍用当前窗口进行观测，更新占用矩阵、拓扑节点和边、访问轨迹、边计数和距目标进展。
⑮ 何时重新做高层规划？地图宽度≥24：每成功前进一格就重新打分。小图：沿A*执行到当前航点后再规划。
大图逐步重规划重新生成 frontier、预测距离、宏观分支、候选得分和A*路线，及时放弃已经变得不合理的旧路线。
小图航点式执行地图短且21×21已接近最优，过多重规划收益很小，因此执行到当前航点再重新选择。
⑯ 防卡死与路线恢复 撞墙：清空路线并重规划。振荡：连续5帧重复 A-B-A-B-A 模式则重规划。重复边：同一条无向边累计走过5次则重规划。失败分支：到达入口后没有新增信息和目标进展，则失败次数+1，并在10步内强降权。逐步重规划：每前进一格清除过时的剩余路线，是最主要的主动防绕路机制。
⑰ 停止条件机器人坐标严格等于终点坐标后执行 STOP；离终点很近但未站上终点不会提前停止。
输出与评测输出成功/失败、实际路径长、SR、SPL、未见格占用预测正确率 AP_UNSEEN；真实最短路径和隐藏地图只在episode结束后用于评测。
一句话理解：机器人先用局部地图预测未知区域，把“可探索入口”合并成几个大方向并打分；A*负责在已确认道路上去航点，执行一格后用新观测和历史经验重新判断，直到真正站到终点。
